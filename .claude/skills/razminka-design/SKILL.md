# Дизайн-система «Разминка»

Метафора бренда: **«съёмка с рук, дневной свет без цветокоррекции»** — живо, честно,
без глянца. Все токены уже подключены через `styles.css` — использовать переменные,
не хардкодить значения.

## Палитра (только эти цвета)

| Токен | Hex | Роль |
|---|---|---|
| `--paper` | #FAFAF8 | фон, холодный белый |
| `--ink` | #14140F | текст, тёмные блоки |
| `--lime` | #C6F432 | маркер-хайлайтер. **Лайм = выгода** (цена, сроки, бонус) |
| `--coral` | #FF4D3D | CTA, REC-точка, служебные акценты |
| `--sand` | #EDEBE3 | подложки карточек, нейтральные торцы |
| `--ink-70/55/38/14` | rgba(20,20,15,…) | приглушённый текст, рамки (`--hairline`) |

**Правило одного акцента:** цветной акцент работает, только когда он один на блок.
Не чередовать coral/lime в соседних элементах («светофор» запрещён).

## Типографика

- **Unbounded** (`--font-display`, вес 700–900) — заголовки. Display-шрифт = структура.
- **Manrope** (`--font-body`) — текст, заголовки карточек.
- **JetBrains Mono** (`--font-mono`) — служебное: лейблы капсом с разрядкой
  (`--ls-mono-wide`), таймкоды, индексы «01», подписи полей форм, микрокопия.
- **Caveat** (`--font-script`) — рукописные пометки (редко).

Иерархия секции: тихая моно-подпись капсом (`--ink-55`) → громкий Unbounded-заголовок.
Жирный Manrope НЕ заголовок — не оформлять им заголовки секций.

## Фирменные идиомы

1. **Лайм-маркер** (HighlightMark): фон-градиент под словом
   `background-image: linear-gradient(var(--lime),var(--lime)); background-size: 100% 0.62em;
   background-position: 0 86%; padding: .02em .14em; rotate(-0.6deg)`.
   После маркера перед знаком препинания правый паддинг убирать
   (`padding-right:.04em; margin-right:-.03em`) — иначе «слово ,» с отрывом запятой.
2. **Наклон «съёмка с рук»**: карточки ±0.5° попеременно (`--tilt`), на hover
   выпрямление + подъём (`translateY(-2px)`, `--shadow-lift`).
3. **Моно-таймкоды**: индексы «01…» в углу карточек, `--fs-mono-sm`, `--ink-38`.
4. **Hero-акцент**: самый сильный пункт списка — отдельная карточка. Лайм-фон +
   чёрный текст (как маркер). НЕ лаймовый текст на чёрном («терминал» запрещён).
5. **Карточки**: `--r-card` (6px), `--hairline` рамка, `--shadow-card`, торец 6px
   `--sand` (нейтральный) или один цветной у hero.
6. **Бейджи**: пилюли `--r-pill`, лайм-фон + ink-текст, моно-капс.

## Композиция

- Одноколоночные страницы — **всё по центру** (текст, заголовки, бейджи);
  по левому краю только текст внутри карточек и поля форм.
- Ритм: крупный H1 (в 2 строки, с лайм-маркером на ключевом) → лёгкий оффер
  (первый абзац крупнее, второй мельче и светлее) → секции с карточками → форма.
- Списки на десктопе — плитки 2×2 + hero на всю ширину (bonus-grid), на мобильном —
  компактные строки. Не делать «широкие пустые баннеры».
- Mobile-first, никакого горизонтального скролла. Кнопки пары — всегда равного размера.

## Формы GetCourse (ГК)

- Виджеты ГК живут в кросс-доменных iframe; страница ГК ставит `html{overflow:hidden}` —
  **внутренняя прокрутка у пользователя не работает**. В попапах форма масштабируется
  под высоту (`transform: scale`), высота приходит postMessage'ем (`uniqName`).
- CSS самой формы задаётся в ГК (HTML-блок со `<style>`): готовые стили —
  `docs/gk-form-1635020.css` (моно-лейблы, поля 6px, коралловая кнопка-пилюль).

## Файлы-источники

- `styles.css` — все токены (цвет, шрифты, отступы, тени).
- `_ds_bundle.js` — React-компоненты DS: HighlightMark, HandCircle, RecIndicator,
  TiltCard, TapedPhoto, StatCard, Accordion и др. (страница `index.html`).
- `anketa.html` — эталон статической страницы на токенах без React.
- `lead-modal.js` — попапы оплаты (рубли + зарубежная карта).

## Запрещено

- Шрифты вне набора (никаких Inter/Roboto/Arial), «ближайшие аналоги» цветов.
- Чередование цветных акцентов подряд; лайм-текст на чёрном; серые дефолтные кнопки.
- `overflow: hidden` на родителях виджетов ГК; фиксированные высоты контента форм.
